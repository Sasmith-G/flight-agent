# Duty-of-Care Matrix — Operational Guidance for Disruption Handling

| Disruption severity | Passenger entitlement | Action for the assistant |
|---|---|---|
| Delay < 2h | None (monitor only) | Keep monitoring; no notification unless requested |
| Delay 2h–3h | Meals, refreshments, communications | Notify passenger, present rebooking options, mention right to care |
| Delay 3h–5h | Care + EUR 250–400 compensation (unless extraordinary circumstances) | Notify with options, state compensation eligibility explicitly |
| Delay > 5h | Care + compensation + right to full refund | Present refund as a first-class option alongside rebooking |
| Cancellation | Refund or re-routing + compensation (if < 14 days notice) | Present earliest re-routing and refund; state compensation eligibility |

## Communication guidelines
- Always state the source of an entitlement (regulation or carrier policy).
- Never promise compensation when the disruption cause is unknown; use
  "you are likely eligible" and reference the applicable rule.
- Present at most 3 rebooking options, ordered by earliest arrival.
